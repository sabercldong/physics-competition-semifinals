# 构建与核验

## 工程目录

每届工程位于 `第NN届/整理版/`：

- `drafts/question-NN.md`：逐题教师主稿，是三版文档的共同内容源。
- `latex/`：排版模板及三版自包含LaTeX源文件。
- `figures/`：可编辑TikZ图稿、矢量PDF及图像；第35届另保留原始测量照片。
- `output/`：三版PDF和Markdown成品。
- `scripts/`：绘图、构建、计算检查、文档检查及独立重建脚本。
- `sources/`：原卷提取资料与资料来源记录。
- `核验/`：计算结果、文档结构检查、编译、视觉审读和重建记录。

原始PDF位于各届目录下。`总审核/2026-10-13/修改前/`保留文字润色前的源稿、成品和核验记录。

## 依赖与运行

使用Python 3.10或更高版本。系统命令需要 `pandoc`、`xelatex`、`qpdf` 和 `pdftotext`；TeX环境需提供中文字体及项目模板使用的宏包。Python依赖在仓库根目录的 `requirements.txt` 中。

在仓库根目录创建环境并安装Python依赖：

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

进入任一届工程后运行，例如第40届：

```sh
cd 第40届/整理版
python scripts/build_all.py
python scripts/verify_physics.py
python scripts/quality_check.py
python scripts/check_rebuild.py
```

第43届另运行补充核验：

```sh
python scripts/verify_enrichment.py
```

`build_all.py`从逐题主稿生成三版Markdown、LaTeX和PDF。修改解析应先修改主稿，再重新生成三版；直接修改生成的LaTeX会在下次构建时被覆盖。

`check_rebuild.py`在独立临时目录重建，比较TeX、逐页文字与逐页渲染像素。字体或TeX环境不同可能产生不同分页，此时需重新审读成品。
